Problem Statement

The current state of public crime data in India is highly fragmented, existing in disparate files and varying formats across different years. Analysts lack a unified, queryable repository, making it difficult to track long-term trends, compare state-level statistics, or uncover crucial socio-demographic correlations (such as literacy versus crime rates). This project is needed to ensure accurate, automated, and insightful analysis of large-scale crime datasets.

Proposed Solution

The system proposes a complete Business Intelligence pipeline. We extract historical and current crime data, transform it into a clean Star Schema, and load it into a centralized Data Warehouse. A Streamlit-based interactive dashboard is deployed on top of this warehouse to enable dynamic Relational OLAP (ROLAP) analysis. This allows end-users to easily slice, dice, and visualize complex metrics through an intuitive web interface.

Scope and Feasibility

The project focuses on integrating multi-source crime and demographic data into a functional Data Cube. It is highly feasible using modern Python libraries (Pandas, Plotly, Streamlit) and SQLite for the backend. The system operates entirely offline with high performance, making it a scalable architecture suitable for academic research, policy-making, and public awareness deployment.
